# Cuba — La hoja de ruta

Plataforma editorial y documental modular sobre soberanía, constitucionalismo y Estado.

## Arquitectura

Blogger funciona como CMS y host del contenido. La aplicación ZenBlog se desarrolla y distribuye desde este repositorio mediante módulos externos, manteniendo el XML de Blogger pequeño y estable.

## Principios

- XML de Blogger mínimo y estable.
- Arquitectura modular basada en principios SOLID.
- Separación entre dominio, contratos, adaptadores, features y UI.
- Metadata explícita; la clasificación documental no se infiere.
- Búsqueda documental explicable y extensible.
- Progressive disclosure: menos interfaz visible, sin perder capacidad.
- Desarrollo LAB antes de producción.
