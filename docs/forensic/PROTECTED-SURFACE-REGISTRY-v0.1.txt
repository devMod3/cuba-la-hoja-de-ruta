OBJETIVO
=======
Definir las superficies cuyo comportamiento se considera contrato del producto o frontera arquitectónica.
Una superficie protegida NO es intocable para siempre. Significa que cualquier cambio requiere alcance explícito, evidencia, owner, regresiones, rollback y validación proporcional al riesgo.

ESCALA DE EVIDENCIA
===================
E0 = afirmación no verificada.
E1 = intención/documentación histórica.
E2 = código o test estático actual.
E3 = QA automatizado de comportamiento/navegador.
E4 = QA manual documentado en Blogger real.
E5 = release aceptada/congelada con SHA/XML/rollback identificables.

PS-001 — ANATOMÍA BLOGGER
=========================
Estado: PROTECCIÓN MÁXIMA
Nivel: E2 actual + E3 histórico
Contrato:
- exactamente un #page_body;
- exactamente un Blog1 bajo #page_body;
- no zen_main como raíz sustituta;
- Blogger conserva documento, URLs y CMS.
Gates: XML well-formed, invariantes CI, Blogger real, rollback XML.

PS-002 — ZEN RADIO PLAYER
=========================
Estado: CONGELADO / REPOSITORIO INDEPENDIENTE
Contrato:
- loader independiente;
- versión protegida documentada 1.0.3;
- ZenBlog no cierra, oculta ni restiliza internals;
- sólo puede reservar espacio mediante contrato de layout.

PS-003 — EXPLORE
================
Estado: CONGELADO
Nivel: E3 histórico + E2 actual
Contrato:
- simple = título solamente;
- accent-insensitive;
- recent-first cuando query vacía;
- advanced = filtros estructurados;
- simple no ejecuta motor avanzado;
- filas = Tipo · Fecha · Título;
- sin resumen;
- año documental != fecha Blogger;
- no popularidad inventada.
