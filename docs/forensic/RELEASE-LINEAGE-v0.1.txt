NIVELES DE ESTADO
=================
EXPERIMENT = rama/PR de prueba; no apta para producción.
CANDIDATE = spec + tests + CI; falta Blogger/aceptación.
VALIDATED = QA real completado.
FROZEN = validado + aceptado + rollback/manifiesto; cambios requieren nueva spec.
