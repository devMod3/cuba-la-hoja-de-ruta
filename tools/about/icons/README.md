# Social SVG sources

Local monochrome assets used by ZenBlog About.

- X, GitHub, YouTube, Telegram, Facebook, Bluesky and Mastodon are derived from the current Simple Icons SVG set.
- Instagram uses a locally redrawn geometric mark for the monochrome UI.
- LinkedIn is derived from Font Awesome Free Brands (`linkedin-in`), whose SVG source carries the Font Awesome Free license notice.
- `other.svg` is a generic local link glyph.

The public UI renders these files as CSS masks so all icons inherit ZenBlog's text/accent color instead of brand colors.

Before redistributing or reusing brand assets outside this project, review the upstream trademark/license guidance for the relevant brand and icon library.
